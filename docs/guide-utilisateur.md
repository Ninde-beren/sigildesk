# SigilDesk — mode d'emploi

**Ouvrir Internet, Facebook, vos mails ou YouTube** : cliquez sur la tuile.
L'ordinateur est modeste : patientez quelques secondes, la fenêtre arrive.

**Revenir à l'accueil** : fermez la fenêtre avec la croix, en haut à droite.

**Vos photos, vidéos et documents PDF** : tuiles du bas. Double-cliquez sur
un fichier pour l'ouvrir.

**Une clé USB** : branchez-la, cliquez sur *Fichiers* ; elle apparaît dans la
colonne de gauche.

**Une tuile qui ouvre un autre dossier** (vos photos sur une clé USB, par
exemple) : *Paramètres* › *Dossiers* › *Choisir un dossier…*. Le bouton
*Revenir à…* rétablit le dossier habituel.

**Vos sites préférés** : bouton *Mes favoris*, en bas. *Ajouter* pour en
garder un nouveau.

**Textes plus grands** : *Paramètres* › *Mode confort*.

**Changer l'image de fond** : *Paramètres* › *Changer le fond d'écran*. Cliquez
sur une image pour l'essayer, puis *Appliquer*.

**Éteindre** : bouton *Éteindre*, en bas, puis confirmez.

En cas de doute, ne forcez rien : appelez la personne qui vous aide.
